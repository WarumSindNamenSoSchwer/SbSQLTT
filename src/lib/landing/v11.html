FAQ
Häufige Fragen


Brauchen Schüler ein Konto?
Zum Ausprobieren nicht. Im Unterricht treten Schüler mit dem Klassencode bei und legen ein Konto mit Benutzernamen an. So bleibt ihr Fortschritt gespeichert.
Für welche Klassenstufen ist Tabula gedacht?
Ab Klasse 10 bis zum Abitur. Die Lektionen bauen aufeinander auf und lassen sich in einzelnen Stunden einsetzen.
Was kostet Tabula?
Nichts. Tabula ist kostenlos und Open Source unter AGPL-3.0.
Muss die Schule etwas installieren?
Nein. Tabula läuft im Browser. Wer möchte, kann es auf einem eigenen Server an der Schule betreiben.
Wo liegen die Daten?
Auf Servern in Deutschland (Hetzner) oder auf dem Server Ihrer Schule. Es gibt keine Werbung und kein Tracking. SQL-Abfragen verlassen den Browser nicht.
Wie geht es nach SQL weiter?
Der Lernpfad führt über den Entwurf einer eigenen Datenbank zu Python und pandas. Im Abschlussprojekt analysieren Schüler eigene Fragestellungen mit echten Daten.
Wie bekomme ich eine Demo?
Schreiben Sie eine kurze E-Mail an kontakt@tabulasql.de. Wir zeigen Ihnen Tabula und richten auf Wunsch eine erste Klasse ein.
